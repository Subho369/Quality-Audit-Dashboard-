# Quality Audit Dashboard | Power BI Project

* Developed an interactive Power BI dashboard to analyze operational quality metrics including defects, fatal errors, sampling efficiency, and quality scores.
* Created DAX measures for KPI calculations such as Sampling %, Defect %, Fatal Error %, and Quality Score %.
* Built interactive visualizations including scatter charts, maps, donut charts, area charts, and performance ranking visuals.
* Performed data cleaning, transformation, and data modeling using Power Query and relational schema design.
* Generated business insights for employee performance, supervisor effectiveness, audit efficiency, and location-based quality analysis.
